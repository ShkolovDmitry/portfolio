FP&A · group reporting

Group Management Report

Problem
A five-entity financial group in four currencies with books in 1C, budget and KPIs in spreadsheets, and a month-end pack assembled manually.
Built
An engine that reads 1C trial balances, maps accounts, translates under IAS 21, eliminates intragroup items and produces three linked statements, budget variance, forecast and business-unit view.
  • P&L vs budget and prior year, EBITDA bridge with FX isolated
  • Consolidating balance sheet and indirect cash flow
  • Business-unit contribution and transfer pricing (cost plus)
  • Rolling 9+3 forecast from drivers; data cube for ad hoc questions
  • 15 reconciliation checks across the three statements

How I build

Contract first

The model stays the single source of truth. Reports read a fixed export layer with named columns and closed lists, so a change in the model cannot silently shift a number.

Prove, then publish

Every pack checks itself before anyone sees it: trial balances balance, statements tie, intercompany nets to zero, counts match. A failed check stops the report.

AI as a pair, not a black box

I write the specification, data contract and checks; code is produced with Claude Code and accepted only when it passes them. This keeps delivery fast and the logic mine.
